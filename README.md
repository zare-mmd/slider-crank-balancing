# slider-crank-balancing
Dynamic balancing optimization of a slider-crank mechanism using Python (optional bonus coursework).
Python script that performs a full kinematic and dynamic analysis of a four-bar linkage mechanism, developed as coursework for the Dynamics of Machinery course at Shiraz University.
What it does:
Solves the position, velocity, and acceleration loop-closure equations for the coupler and rocker links across a full revolution of the crank
Computes joint reaction forces on each link using a Newton-Euler style force balance
Animates the mechanism's motion over one full crank revolution
Tools
Python, NumPy, SciPy (fsolve), Matplotlib
Background

This was required coursework, submitted and graded as part of the Dynamics of Machinery course.
